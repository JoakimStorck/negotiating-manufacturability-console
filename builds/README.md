# Builds

The instructions for the tool's own builds, each `<name>-build.md` with its report `<name>-build-report.md` beside it, written,
built and reported as am-llm's builds are. A build that touches the tool alone lives here: its pages, its layout, its command line,
its own documents. A build that touches both repositories (a contract, the frame and the tool together) lives in am-llm's
`probes/`, in parts, one per repository, with the pin and the contract tests on am-llm's side; `DEVELOPMENT.md` 6 names where
each build is.

The builds before this folder (decided 2026-11-09) are in `../am-llm/probes/`: `order-tool-build.md`, `frame-client-build.md`,
`overview-build.md`, `layout-build.md`, `makers-selector-build.md`, `order-2-build.md`, `dialogue-build.md`, each with its report.
